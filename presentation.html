  • "The interesting design decision is the split. The model is good at deciding where to look next. It's bad at counting and at not inventing quotes. So it never sees raw data and never writes a number."
  • The data handling diagram runs inside every collection tool, before the agent sees anything: names hashed with a salt in the same function that receives them, personal details redacted, then date, duplicate, spam and Haiku relevance filters.
  • Pink steps are model steps, yellow steps are code.
  • If asked about probes: a new search starts full size only on a platform that's at least 70% relevant over 2+ searches.
  • If asked about login: no source uses our account or cookies. LinkedIn posts need a login to view, and the evidence drawer says so.
  • If asked about editorial and Trends: context only, never counted as audience voice.
  • If asked "why your own loop, not the Agent SDK?": the tools enforce budgets deterministically, and the loop is small enough to test offline with recorded transcripts.

    SIGNAL · Context Packs03 / 04 · From posts to a claim
  • "This is the part the demo can't show you: how a scraped post becomes something the tool will call a fact."
  • Walk the gates left to right: pink = a model step, yellow = a code step. The model never outputs a count (metrics.py); quotes are checked as exact substrings (verify.py); safe_to_assert = strong + observed + supported (confidence.py).
  • Step 04: the generic answer is written with no evidence. Findings it already covers aren't marked "non-obvious".
  • Entailment is checked by Opus, a stronger model than the writer: 137 of 150 sampled claims.
  • "Even a strong finding isn't safe to state if it's our interpretation. The student-budget theme on slide 1 scores 0.82 and is strong, but it's inferred, so it isn't marked safe."
  • The downstream test (scripts/demo_agent): with the pack, the scripts used 8 audience terms and cited 16 pack items, but still stated 4 facts not marked safe. Say it plainly: rules in a prompt aren't enough, which is why the pipeline enforces everything in code.
  • If asked "isn't 100% quotes trivially true?": yes, that's the point. It's a guarantee, not a score, so it isn't counted as an eval result.
  • System: one free Render service runs the web app, API, MCP and the worker; Neon stores everything, so runs survive restarts (heartbeat every 20 s, resumed once). Only Anthropic and Apify cost money.
  • "Why not RAG or embeddings?" Clustering with a membership check plus exact-substring quotes keeps every claim traceable. Local ML models also don't fit a free 512 MB server (peak 201 MB).
  • "Limits aren't in the prompt; the tools refuse." Every number on this slide comes from modes.yaml and is enforced in collect/tools.py.

    SIGNAL · Context Packs04 / 04 · What I learned · what's next
  • Product thinking: "I'm not a marketer, so I tested early with four who are: a freelance B2B marketer, a lifecycle marketer, a former CMO and a B2B SaaS marketer."
  • Internally the changes are numbered V1–V13 (in CHANGELOG.md); X and Facebook were added alongside V6. Keep the full list ready in case someone asks.
  • "I didn't write a wishlist. Every item starts from a number I measured in the evals or heard in the user tests, and ends with the number that tells me it's done."
  • Relevance by brief: Gen Z 80%, heat pumps 74%, NL snacks 51%, vague snacks 50%, UK brand range 34%. Off-topic posts never become evidence, but they cost collection time.
  • The 4 unsafe facts: with the pack, a Claude agent writing TikTok scripts still stated 4 facts the pack hadn't marked safe; a code check in the test flagged them. Prompts alone don't hold, so the fix is enforcing it in the skill and MCP.
  • Speed: 14–17 min in the latest Quick runs. The 69–102 min on /evals includes analysis I finished later with extra budget, so nobody should think it was hidden.
  • Next: the worker can move to its own machine without changing the API or URL, because runs are jobs in the database. Forum feeds (V13) are new and not yet proven in a full run.
  • Later: present who pays, and the format, as hypotheses I'm testing. The run cost sets the price floor. Positioning to test: quote-backed audience voice, local and multilingual.
  • "Isn't scraping a privacy problem?" Public posts only, keyword search only, names hashed on arrival, 30-day expiry, 280-character excerpts, quotes not for public reuse.
